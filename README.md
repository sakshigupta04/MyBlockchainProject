
# My Blockchain Project

## Project Overview

This is a beginner-friendly blockchain project created using Solidity.
The project demonstrates how a smart contract can store and retrieve a number on the blockchain.

## Use Case

The smart contract can be used as a simple example of storing and retrieving information on a blockchain.
It helps beginners understand how blockchain data can be written and read using a smart contract.

## Technologies Used

- Solidity
- Ethereum Blockchain
- Remix IDE
- MetaMask

## Demo

The smart contract provides two main functions:

- `setNumber()` - stores a number in the smart contract.
- `getNumber()` - retrieves the stored number.

Example:

Number stored: 25

Number retrieved: 25

## Limitations

- This is a beginner-level demonstration project.
- It stores only a simple number.
- It is not designed for storing sensitive or large amounts of data.
- Transaction fees may be required when using a real blockchain network.

## Security Notes

- Never share your wallet private key or recovery phrase.
- Use a test network for learning and testing.
- Do not use real funds for this beginner project.
- Smart contracts should be properly tested before being used with real assets.

## Conclusion

This project demonstrates the basic working of a Solidity smart contract and provides a simple introduction to blockchain-based data storage and retrieval.
